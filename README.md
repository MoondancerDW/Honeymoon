# Honeymoon

Исходная карта Equestria и браузерный прототип Honeymoon.

Архивы мира публикуются в [релизах](https://github.com/MoondancerDW/Honeymoon/releases). Распакуйте все части в один каталог, чтобы объединить регионы мира.

Реализация и команды запуска находятся в `project/`. Для импорта оригинального визуала нужен локальный комплект Honeymoon с исходным текстурпаком и ресурсами модов.
