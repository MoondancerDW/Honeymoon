# Извлечение моделей Jammy Furniture 4.1

Из `project/` запустите `python world/jammy-models.py`. Нужны Pillow и JDK 8.
Если JDK отсутствует в `PATH`, укажите его через `--java-home` или `JAVA_HOME`.
Параметры `--source` и `--output` задают каталог оригинального клиента и каталог
результатов. По умолчанию скрипт записывает `generated/models/jammy.json` и
`generated/models/jammy.png`.

Скрипт читает числовые ID из `config/JammyFurnitureMod.conf`, загружает
оригинальные классы блоков, моделей и рендереров из архива мода. Из клиентского
`minecraft.jar` используются `ModelRenderer`, `ModelBox`, `TexturedQuad` и
`AxisAlignedBB`. Оригинальные рендереры определяют выбор модели и текстуры,
порядок поворотов, переносы и масштаб. Перехватчик записывает вершины и UV,
которые `TexturedQuad` передаёт в `Tessellator`, и применяет к ним матрицу
рендера. Перехватчики имеют имена классов из клиента 1.4.7, поскольку JVM
разрешает ссылки оригинальных классов по этим именам.

Границы выделения и коллизии извлекаются раздельно. Для каждого состояния
выполняются оригинальные методы блока, которые меняют границы в зависимости от
metadata. Обработаны также блоки с несколькими коллизиями и без коллизии.
Координаты локальные относительно ячейки, `v=0` находится на верхней границе
атласа. Изображения берутся по точному пути, который рендерер передаёт клиенту.

Каталог содержит 320 состояний. Для холодильника, морозильника и
посудомоечной машины извлечены 12 вариантов открытой дверцы с теми же
поворотами и текстурами. Исходный рендерер вычисляет конечный поворот при
`prevLidAngle = lidAngle = 1`. Браузер переключается между конечными
положениями и воспроизводит исходный звук. Коллизии блока одинаковы при
обоих положениях. Действие открывает модель дверцы, содержимое и GUI
бытовой техники пока доступны в оригинале.
