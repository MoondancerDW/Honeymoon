# Запуск Lilium Moonlight

Для локального теста на Windows x64 распакуйте готовый ZIP и запустите
`Start-Lilium-Moonlight.cmd`. В тестовый комплект входят карта, модели, текстуры,
звуки и Node.js. Основная инструкция ниже описывает сборку из исходников.

Нужны Node.js 24 с npm и Python 3.10+ с Pillow. Команды выполняются
из каталога `project`. Сервер Minecraft не требуется.

Из каталога project:

```sh
npm ci
python -m pip install -r world/requirements.txt
npm run import:world -- --city
python world/textures.py
python world/native-interface.py
python world/jammy-models.py
python world/biblio-extract.py
python world/redpower-lamps.py
python world/sounds.py
node import/snow-cleanup.mjs --world generated/world --out generated/world/snow-cleanup.json
node import/lod.mjs --world generated/world --out generated/lod
node import/vista.mjs --world ../sources/Honeymoon/saves/equestria --out generated/vista --bounds=-312,-416,343,343
npm start
```

Откройте [127.0.0.1:4173](http://127.0.0.1:4173/). Сервер по умолчанию
слушает только локальный интерфейс. Если системный python на Windows
указывает на Microsoft Store, используйте путь к установленному Python.
Для этой локальной среды подготовлен [Start-Honeymoon.ps1](Start-Honeymoon.ps1).

Импорт читает исходный мир из `../sources/Honeymoon/saves/equestria/`.
Архивы карты из [GitHub Release](https://github.com/MoondancerDW/Honeymoon/releases/tag/equestria-source)
распаковываются в `sources/Honeymoon/saves/` так, чтобы получился каталог
`equestria/region/`. Для исходного визуала добавьте в `sources/Honeymoon/` пять архивов
текстурпака и модов из [манифеста](legacy/README.md). Их можно проверить
командой `node legacy/verify-inputs.mjs atlas`.
Альтернативные пути задаются
`node import/anvil.mjs --world …` и `python world/textures.py --source …`.
Оригиналы открываются для чтения. Промежуточные файлы, производные текстуры и
SQLite сохраняются под `project/`.
Для извлечения моделей Jammy Furniture нужен оригинальный `minecraft.jar`
и Java 8 JDK. Укажите `--java-home`, если JDK отсутствует в `PATH`.
BiblioCraft и RedPower читают ресурсы из исходных архивов. Сборка атласа
BiblioCraft также берёт изображения настенных карт из исходного сохранения по
рамкам, попавшим в импортированные чанки.
Атласы и каталоги моделей сохраняются в `generated/models`.
Интерфейс предметов берётся из активного текстурпака исходного клиента Minecraft,
а броня пони из исходного `minecraft.jar` и архивов модов.
Оба атласа сохраняются в `generated/textures`.
Звуки читаются из `sources/Honeymoon/resources`, активного пакета Audiotori
и архивов модов. Каталог воспроизведения, Ogg и WAV сохраняются в `generated/sounds`.
Для Chisel используется оригинальный архив `mods/ChiselRetro_beta0.9_mc1.4.7.zip`.

## Карта и управление

С полным набором `generated/full-world` доступен весь прямоугольник Эквестрии.
Границы по координатам Anvil включительны. X от −4992 до 5503, Z от −6656 до 5503,
Y от 0 до 511. Чанки подгружаются вокруг игрока в пределах горизонта.
На телефоне работают стик и свайп для обзора. Прыжок, спуск, установка,
удар и действие доступны отдельными кнопками. Остальные команды открываются
через «Ещё». В мобильном режиме горизонт составляет 24 чанка, а число
пикселей ограничено эквивалентом 1280×720. Целевой темп отрисовки — 30 кадров/с.
Переключатель «Упрощённая графика» действует и на компьютере, и на телефоне.
Она сохраняет выбор в браузере и сокращает разрешение, дальние чанки и
декоративные эффекты.
Ближние 4 чанка используют точную
геометрию. В меню паузы можно выбрать дальность более подробной упрощённой
сетки — 8, 12, 16, 20, 24 или 28 чанков. Выбор сохраняется в браузере.
За 32 чанками продолжается обзор основного прямоугольника Эквестрии.
Для дальнего обзора используются подготовленные высоты, цвета и отдельная геометрия навесов
и объектов в воздухе. В пределах района
дальние тайлы сохраняют форму ступеней и конструкций из микроблоков,
а также освещение исходной карты.
Постройки игроков видны при приближении,
когда тайл сменяется точным чанком. Коллизии, наведение и правки работают
с точными чанками вокруг игрока. В сборке без `generated/full-world`
игровая область охватывает Понивилль, окрестности, Вечнодикий лес и Замок Двух Сестёр.
Для эксперимента с отсечением закрытых секций откройте
локальный адрес с `?occlusion=1`.
Игрок появляется в `(-7.5, 65, -19.5)`,
в центре ячейки над исходным спавном `(-8, 64, -20)`.

Игроки начинают в игровом режиме. В нём могут летать пегасы и аликорны.
Администратор может назначить креатив себе или другому игроку. В креативе летают все расы.
Землю и растения можно собрать вручную, а инструмент выбирается по материалу.
Из брёвен, досок и булыжника можно изготовить основные инструменты.
У земных пони и аликорнов 15 единиц здоровья, у остальных рас 10. Удар другого игрока снимает одну единицу.
Пегасы и аликорны защищены от урона падения. Для остальных первые три блока падения безопасны.
После урона здоровье возвращается по единице за пять секунд.
После смерти можно вращать камеру, пока кнопка «Ожить» не вернёт управление.

В паузе администратору доступно меню «Администрирование» с приглашениями,
профилями, режимами игроков, временем, погодой и редактором NPC.
Из списка профилей можно телепортироваться к подключённому игроку,
переместить его к себе, заблокировать профиль или снять блокировку.
NPC открываются на E. Ключ владельца создаётся в `state/npc-admin.key`
при первом запуске Windows-сборки. Для запуска с исходников используйте
переменную `HONEYMOON_NPC_ADMIN_KEY`. Герои, торговля, диалоги и задания
подгружаются из `generated/npcs/original.json`. Этот файл можно восстановить
командой `npm run import:npcs -- --world <сохранение> --manifest <full-world/manifest.json> --out <original.json>`.

WASD или стрелки двигают игрока. Пробел позволяет прыгать и подниматься
в воде, C или Ctrl опускает игрока в воде. Shift в глубокой воде переключает
пони на горизонтальное плавание. На лестнице можно подняться,
двигаясь вперёд или удерживая пробел. В западном подвале можно выбраться
через открытый люк по добавленной верхней ступени. ЛКМ ломает блоки со звуком
и частицами материала. При беге с Shift частицы летят назад из-под копыт.
При падении с высоты они разлетаются от места приземления.
O или средняя кнопка копирует блок или микроблок под прицелом. Q выбрасывает
один предмет, Ctrl+Q — всю стопку. Предметы падают, лежат на поверхности и
исчезают через десять минут или при остановке сервера. Одно нажатие C подбирает один ближайший
доступный предмет с земли. Удержание C продолжает приседание.
V включает и выключает ползание. Прыжок лёжа достигает половины блока.
X усаживает пони на поверхность или поднимает. Сидя можно перемещаться
со скоростью ползания. Удержание направления движения в течение секунды поднимает пони.
Если над пони низкий потолок, он поднимется, когда для этого будет место.
Переключение ползания сделано по образцу [Crawl](https://github.com/fewizz/crawl).
В паузе кнопка «Предметы» открывает вкладки в порядке исходной сборки,
то же делает I. J открывает инвентарь с четырьмя ячейками брони.
Цифры 1–9 и колесо выбирают ячейку панели. Перетащите
предмет на панель или в инвентарь. Чтобы удалить стопку, перетащите её в корзину.
СКМ копирует стопку. Ячейка с карандашом открывает редактор названия и описания.
ПКМ с книгой в руке открывает её. Страницы черновика сохраняются при наборе и закрытии.
По каталогу можно искать по названию, моду и ID. ПКМ ставит выбранный блок.
Удержание ПКМ после паузы 0,35 секунды повторяет установку блоков
и микроблоков до отпускания кнопки. Каталог включает блоки из оригинального реестра, в том числе те,
которые не встречаются на карте. Технические состояния выделены в отдельную
вкладку. Состояния, которые нельзя поставить самостоятельно, видны серыми.
E взаимодействует с дверями, люками, калитками, сундуками, кнопками, рычагами и мебелью.
Пока открыто хранилище, предметы можно перетаскивать между его ячейками и инвентарём.
Нажмите E, чтобы отредактировать табличку, лечь на кровать, сесть на кресло или в вагонетку.
Повторное E возвращает на ноги.
Железные двери открываются от сигнала, например от кнопки.
ПКМ ставит выбранный блок у выбранной грани. Найдите табличку в каталоге и
поставьте её сверху или сбоку блока. Наведите прицел на поставленную
табличку и нажмите E, чтобы написать или изменить до четырёх строк.
Рамку можно ставить на стену, пол или потолок. ПКМ с выбранным предметом
или блоком помещает его в рамку, E поворачивает. ЛКМ сначала вынимает
содержимое, затем снимает пустую рамку. В каталоге также есть невидимая рамка.
В каталоге есть рельсы, энергорельсы, рельсы с датчиком и пассажирская
вагонетка. Поставьте рельсы на опору и нажмите ПКМ по пути с вагонеткой
в руке. E позволяет сесть и выйти, W/S или ↑/↓ — поехать. Стоящую вагонетку
можно толкнуть пешком вдоль пути. Энергорельсы ускоряют вагонетку при
питании и тормозят без него. Рельс с датчиком выдаёт сигнал при проезде.
Выберите лодку в каталоге и поставьте её ПКМ на воду. E позволяет сесть
и выйти. Управляйте лодкой с помощью WASD или стрелок.
Y и F5 переключают виды от первого лица, сзади и спереди. U включает
свободное вращение камеры вокруг пони. B приветствует взмахом копыта,
Z включает танец до начала движения. K управляет резцом. Скорость спринта с Shift зависит от расы.
F включает доступный персонажу полёт. Пробел поднимает, Ctrl или C опускает. Высота влияет на скорость полёта.
Стены, потолки и границы карты действуют и в полёте. Администратору G открывает телепорт по координатам.
Камера от первого лица покачивается при ходьбе. Днём по небу движутся
облака, ночью видны звёзды. Мягкие контактные тени заметны в углах блоков
и под видимыми моделями игроков. Esc открывает и закрывает паузу слева. Звук и музыка
настраиваются отдельно в браузере. В меню «Громкость и окружение» можно
выбрать звуковой профиль и отрегулировать громкость и частоту природы,
животных и прочих звуков. Порывы ветра слышны и видны по движению травы
и листвы. В паузе можно переключить общую погоду между ясной, облачной
и дождливой. На Y 160 и выше, а также в горных биомах на любой высоте
вместо дождя идёт снег со своим звуком. В дождь изредка слышен гром.
Ночное зрение действует только у игрока,
который его включил. Облака закрывают луну и звёзды, а свет под землёй
зависит от проёмов и факелов.
Факелы и другие светящиеся предметы в руке освещают поверхности поблизости.
E включает радио Jammy. Shift + E воспроизводит смыв у туалета Jammy.
Shift + E открывает и закрывает крышку витрины BiblioCraft.
У скопированной секции дивана R поворачивает предпросмотр. Секции одного
цвета соединяются со стороны сиденья и меняют форму при добавлении или
удалении соседней секции. Секции деревянных сидений, обращённые в одну
сторону, образуют скамью. Заборы и другие соединяемые блоки обновляются при изменении соседей.
На сенсорном экране доступны стик, свайп для обзора и кнопки действий.

Укажите ник и, при желании, выберите PNG-скин пони перед входом в мир.
Поддерживаются PNG 64×32, 64×64, 128×64, 256×128 и 512×256 размером до 576 КБ.
У файлов 64×64 модель использует верхнюю половину. Ник и скин можно менять
в меню Esc. Смена ника объявляется в общем чате. Размер из служебного пикселя
скина определяет габариты при ходьбе, приседании и ползании. Ник над пони
скрывается при приседании, ползании, лежании и за непрозрачными преградами.
Откройте один адрес сервера в обоих браузерах, чтобы
видеть пони друг друга. Для проверки двух игроков на одном ПК используйте
разные профили браузера, чтобы получить отдельные гостевые сеансы.
В портативной Windows-сборке `Start-Server.cmd` разрешает вход
с других ПК в локальной сети. Игроки открывают IP компьютера с сервером
на порту 4173. Модели пони извлечены из Mine Little Pony, мода Verdana
и других участников проекта. Для повторного извлечения используется
`python world/pony-extract.py`. [Mine Little Pony](https://minelittlepony-mod.com/about/)

У микроблоков RedPower подсвечивается выбранная деталь. Скопируйте её клавишей
O или средней кнопкой и наведитесь на место установки. Предпросмотр показывает форму и позицию.
Деталь следует за прицелом по поверхности с шагом 1/8. R поворачивает её,
ПКМ ставит, ЛКМ снимает выбранную деталь. В одном кубе можно совмещать и
складывать детали разной формы и материала, если они не пересекаются.
С пустой рукой ЛКМ убирает все детали из выбранной составной ячейки.
Воду или лаву можно поместить ПКМ в свободный объём полублока, ступени
или ячейки с микроблоками. Источники и потоки стекают вниз, растекаются по
поверхности и отступают после удаления источника. Пустое ведро набирает источник,
полное ставит его. В каталоге есть фальшивая вода. Через неё можно проходить
без замедления, она сохраняет вид воды и остаётся в поставленной ячейке.
В ячейке с микроблоками ЛКМ сперва убирает жидкость, после чего детали снова
можно редактировать.
Эта установка рассчитана на обычные ячейки RedPower Covers. Детали проводов,
труб и подвижных рам можно копировать, если они доступны прицелу.

Z переключает режим резца, B меняет размер детали между 1/8 и 1/4.
O или средняя кнопка берёт материал. ЛКМ снимает выбранную деталь,
ПКМ добавляет деталь у подсвеченной грани. В режиме 1/8 можно разбить
поставленную деталь 1/4 на меньшие части. В одной ячейке можно смешивать
материалы и вырезать форму из полного блока, установленного игроком.
Вода и лава, включая потоки, тоже служат материалом. Поставленные резцом
кубики остаются на месте и пропускают игрока. Вода сохраняет свойство плавания,
лава светится.

Переключатель рядом со спавном стоит в `(-10, 65, -22)`.
Он управляет дверью в двух ячейках с X −9, Z −22, Y 65–66. Вход
в ячейку переключателя один раз сохраняет персональный флаг и показывает
сообщение. Сервер хранит инвентарь по постоянному UID профиля. Игровое имя
можно изменять независимо от имени профиля.

Время суток синхронизируется с сервером. Одна игровая минута длится две
реальные секунды. При изменении состояния лампы
или перекрытии света ближайшие поверхности обновляют освещение.
Вход открывается после подготовки участка вокруг игрока. Остальная карта
подгружается во время игры с приоритетом ближайших чанков.
При телепорте в непрогруженный район экран закрывается до готовности
точной геометрии.
P включает наблюдателя с полётом сквозь блоки от первого лица.
При выходе из режима внутри блока игрок перемещается вверх к свободной
поверхности.

## Размещение и резервная копия

Параметры запуска задаются переменными окружения.

| Переменная | Назначение |
| --- | --- |
| HOST | Интерфейс, по умолчанию 127.0.0.1. Для теста с телефона по LAN используйте 0.0.0.0 |
| PORT | Порт, по умолчанию 4173 |
| HONEYMOON_GENERATED | Каталог производных карт и текстур, по умолчанию project/generated |
| HONEYMOON_STATE | Путь к файлу SQLite, по умолчанию project/state/honeymoon.sqlite |
| HONEYMOON_SECURE_COOKIE | 1 за HTTPS-прокси |
| HONEYMOON_ORIGIN | Публичный origin для проверки запросов на изменение мира |
| HONEYMOON_TAILSCALE_EXECUTABLE | Путь к Tailscale CLI для портативного запуска из нестандартной папки |

Для общего доступа запустите один экземпляр Node за HTTPS-прокси.
Портативный запускатель при занятом другой программой порте автоматически
выбирает следующий свободный порт и открывает его адрес. Повторный запуск
открывает работающий экземпляр из той же папки. Для смены локального, LAN
или интернет-режима сначала закройте его окно запуска. Закрытие консольного окна и Ctrl+C
завершают сервер с сохранением состояния транспорта.
Разрешите потоку SSE `/api/events` работать без буферизации. Браузер
и API обслуживаются с одного адреса. Текущие координаты игроков живут
в процессе сервера и при полном перезапуске возвращаются к спавну.

Для домашнего Windows-сервера установите Tailscale, войдите и запустите
`Start-Internet.cmd` из распакованной сборки от имени администратора.
После первого подтверждения Funnel выдаёт игровой HTTPS-адрес. Браузер
владельца открывается на отдельном локальном порту. Введите ключ из
`state/npc-admin.key`, задайте имя профиля и создайте приглашения игрокам
и администраторам в паузе. Игрокам достаточно браузера.
Запускатель проверяет текущие маршруты Tailscale и выбирает свободный
HTTPS-порт из 443, 8443 и 10000.
[Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel)

Приглашение используется один раз. Выбранное имя профиля отображается
в паузе. Для входа с другого устройства администратор создаёт приглашение
для существующего профиля. Оно сохраняет его UID, роль и инвентарь.
Администратор может отозвать приглашение и доступ отдельных браузеров.

T и Enter открывают чат с прокручиваемой историей последних 100 записей.
Кнопка «Всем» или «Рядом» задаёт получателей следующего сообщения.
Локальные сообщения получают игроки в радиусе 18 блоков, а общие помечены
зелёным `[G]`. Удержание Tab показывает игроков на сервере.
Оба канала записываются в `state/chat-logs` с ником и временем сервера.
Для каждого календарного дня создаётся свой файл.
Клавиша L открывает общие часы, где можно поменять время и заморозить его.

```sh
node server/backup.mjs
node server/backup.mjs state/backups/manual.sqlite
```

Команда создаёт согласованный снимок работающей SQLite. Для восстановления
остановите сервер и укажите копию в `HONEYMOON_STATE`. Храните с копией
версию импортированной карты или исходные регионы. При смене базовой
карты сервер переносит изменения по стабильным ключам и печатает
конфликты. Конфликты также записываются в таблицу `rebase_conflicts`.

### Восстановление исходных построек

Остановите сервер и распакуйте `Honeymoon-Original-Map.zip` отдельно
от каталога установленной игры. В Windows из каталога игры запустите команду,
указав путь к распакованной папке `world`.

```powershell
.\runtime\node.exe server\restore-original-map.mjs --backup-world "C:\Honeymoon-Original-Map\world"
```

Команда сверяет версию карты и нужные чанки с резервной копией, сохраняет
снимок SQLite в `state/backups` и восстанавливает исходные блоки и части
в свободных местах. Постройки игроков сохраняются. Если новая постройка
занимает исходное место, оно отмечается в отчёте и остаётся за постройкой.

## Проверки

```sh
npm test
node world/audit.mjs
node qa/browser.mjs
node qa/desktop-play.mjs
node qa/chisel-desktop.mjs
node qa/chisel-fluids-desktop.mjs
node qa/audio.mjs
node qa/building-survey.mjs generated/world work/building-survey/extended generated/models --extended
```

Браузерный сценарий использует установленный Microsoft Edge, URL из
`HONEYMOON_URL` или локальный адрес выше. Запускайте его с отдельной
тестовой SQLite. Скриншоты и измерения сохраняются в `work/browser-qa/`.
Обход сохраняет координаты, дверные действия и точки съёмки в `work/building-survey/`.
Результаты сверки с Minecraft 1.4.7 описаны в [отчёте об обходе](qa/REFERENCE-ROUTE.md).
В [отчёте](REPORT.md) описаны замеры и визуальные замены, в
[описании импорта](import/README.md) — формат данных.
