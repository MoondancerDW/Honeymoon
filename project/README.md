# Запуск Honeymoon

Для локального теста на Windows x64 распакуйте готовый ZIP и запустите
`Start-Honeymoon.cmd`. В тестовый комплект входят карта, модели, текстуры,
звуки и Node.js. Основная инструкция ниже описывает сборку из исходников.

Нужны Node.js 24 с npm и Python 3.10+ с Pillow. На этой машине проект
находится в D:\Honeymoon-transfer\project. Сервер Minecraft не требуется.

Из каталога project:

```sh
npm ci
python -m pip install -r world/requirements.txt
npm run import:world -- --city
python world/textures.py
python world/jammy-models.py
python world/biblio-extract.py
python world/redpower-lamps.py
python world/sounds.py
npm start
```

Откройте [127.0.0.1:4173](http://127.0.0.1:4173/). Сервер по умолчанию
слушает только локальный интерфейс. Если системный python на Windows
указывает на Microsoft Store, используйте путь к установленному Python.
Для этой локальной среды подготовлен [Start-Honeymoon.ps1](Start-Honeymoon.ps1).

Импорт читает исходный мир из `../sources/Honeymoon/saves/equestria/`.
Архивы карты из [GitHub Release](https://github.com/MoondancerDW/Honeymoon/releases/tag/equestria-source)
распаковываются в `sources/Honeymoon/saves/` так, чтобы получился каталог
`equestria/region/`. Для исходного визуала добавьте в `sources/Honeymoon/` пять архивов
текстурпака и модов из [манифеста](legacy/README.md). Их можно проверить
командой `node legacy/verify-inputs.mjs atlas`.
Альтернативные пути задаются
`node import/anvil.mjs --world …` и `python world/textures.py --source …`.
Оригиналы открываются для чтения. Промежуточные файлы, производные текстуры и
SQLite сохраняются под `project/`.
Для извлечения моделей Jammy Furniture нужен оригинальный `minecraft.jar`
и Java 8 JDK. Укажите `--java-home`, если JDK отсутствует в `PATH`.
BiblioCraft и RedPower читают ресурсы из исходных архивов. Сборка атласа
BiblioCraft также берёт изображения настенных карт из исходного сохранения по
рамкам, попавшим в импортированные чанки.
Атласы и каталоги моделей сохраняются в `generated/models`.
Звуки читаются из `sources/Honeymoon/resources`, активного пакета Audiotori
и архивов модов. Каталог воспроизведения, Ogg и WAV сохраняются в `generated/sounds`.
Для Chisel используется оригинальный архив `mods/ChiselRetro_beta0.9_mc1.4.7.zip`.

## Район и управление

Игровая карта включает Понивилль, окрестности, Вечнодикий лес и Замок Двух Сестёр.
Границы по координатам Anvil включительны. X от −1984 до 831, Z от −880 до 1055,
Y от 0 до 255. Чанки подгружаются вокруг игрока в пределах горизонта.
Игрок появляется в `(-7.5, 65, -19.5)`,
в центре ячейки над исходным спавном `(-8, 64, -20)`.

WASD или стрелки двигают игрока. Пробел позволяет прыгать и подниматься
в воде, Shift опускает игрока в воде. На лестнице можно подняться,
двигаясь вперёд или удерживая пробел. В западном подвале можно выбраться
через открытый люк по добавленной верхней ступени. ЛКМ ломает блоки, которые
вы установили сами. Гостевой профиль определяется cookie браузера.
Q или средняя кнопка копирует блок или микроблок под прицелом. X очищает руку.
I или кнопка «Блоки» открывает креатив. Выберите вкладку или найдите блок
по названию, моду либо ID. Нажмите на карточку, затем поставьте выбранный
блок ПКМ. Каталог включает блоки из оригинального реестра, в том числе те,
которые не встречаются на карте. Технические состояния выделены в отдельную
вкладку. Состояния, которые нельзя поставить самостоятельно, видны серыми.
E взаимодействует с дверями, люками, калитками, сундуками, кнопками, рычагами и мебелью.
Железные двери открываются от сигнала, например от кнопки.
ПКМ сажает на сиденье или кровать и позволяет встать. На остальных блоках
ПКМ ставит выбранный блок у выбранной грани.
F включает и выключает полёт. В полёте WASD управляет движением, пробел
поднимает, Shift опускает. Стены, потолки и границы карты действуют и в полёте.
Esc возвращает курсор. Звук и музыка включаются отдельно в браузере.
У блоков Jammy E включает радио или воспроизводит смыв.
Shift + E открывает и закрывает крышку витрины BiblioCraft.
У скопированной секции дивана R поворачивает предпросмотр. Секции одного
цвета соединяются со стороны сиденья и меняют форму при добавлении или
удалении соседней секции. Секции деревянных сидений, обращённые в одну
сторону, образуют скамью. Заборы и другие соединяемые блоки обновляются при изменении соседей.
На сенсорном экране доступны стик, свайп для обзора и кнопки действий.

Укажите ник и, при желании, выберите PNG-скин пони перед входом в мир.
Поддерживаются раскладки Mine Little Pony 64×32, 128×64 и 256×128.
У файлов 64×64 модель использует верхнюю половину. Ник и скин сохраняются
для гостевого профиля. Чтобы сменить их, нажмите Esc, измените их в меню
и вернитесь в игру. Откройте один адрес сервера в обоих браузерах, чтобы
видеть пони друг друга. Для проверки двух игроков на одном ПК используйте
разные профили браузера, чтобы получить отдельные гостевые сеансы.
В портативной Windows-сборке `Start-Honeymoon.cmd --lan` разрешает вход
с других ПК в локальной сети. Игроки открывают IP компьютера с сервером
на порту 4173. Модели пони извлечены из Mine Little Pony, мода Verdana
и других участников проекта. Для повторного извлечения используется
`python world/pony-extract.py`. [Mine Little Pony](https://minelittlepony-mod.com/about/)

У микроблоков RedPower подсвечивается выбранная деталь. Скопируйте её клавишей
Q и наведитесь на место установки. Предпросмотр показывает форму и позицию.
Деталь следует за прицелом по поверхности с шагом 1/8. R поворачивает её,
ПКМ ставит, ЛКМ снимает свою деталь. В одном кубе можно совмещать и
складывать детали разной формы и материала, если они не пересекаются.
Исходные и чужие детали защищены.
Эта установка рассчитана на обычные ячейки RedPower Covers. Детали проводов,
труб и подвижных рам можно копировать, если они доступны прицелу.

V переключает режим резца с сеткой 8×8×8 внутри блока. Q или средняя кнопка
берёт материал с выбранной поверхности. ЛКМ вырезает выбранный кубик
размером 1/8 блока, ПКМ добавляет такой кубик у подсвеченной грани. Можно начать новую
скульптуру в пустой ячейке или вырезать форму из своего блока размером 1×1×1.
В одной ячейке можно смешивать материалы. Исходная карта и чужие постройки защищены.
Вода и лава, включая потоки, тоже служат материалом. Поставленные резцом
кубики остаются на месте и пропускают игрока. Вода сохраняет свойство плавания,
лава светится.

Переключатель рядом со спавном стоит в `(-10, 65, -22)`.
Он управляет дверью в двух ячейках с X −9, Z −22, Y 65–66. Вход
в ячейку переключателя один раз сохраняет персональный флаг и показывает
сообщение. Гостевой идентификатор хранится в cookie браузера.

Время суток синхронизируется с сервером. При изменении состояния лампы
или перекрытии света ближайшие поверхности обновляют освещение.
Вход открывается после подготовки участка вокруг игрока. Остальная карта
подгружается во время игры с приоритетом ближайших чанков.

## Размещение и резервная копия

Параметры запуска задаются переменными окружения.

| Переменная | Назначение |
| --- | --- |
| HOST | Интерфейс, по умолчанию 127.0.0.1. Для теста с телефона по LAN используйте 0.0.0.0 |
| PORT | Порт, по умолчанию 4173 |
| HONEYMOON_GENERATED | Каталог производных карт и текстур, по умолчанию project/generated |
| HONEYMOON_STATE | Путь к файлу SQLite, по умолчанию project/state/honeymoon.sqlite |
| HONEYMOON_SECURE_COOKIE | 1 за HTTPS-прокси |
| HONEYMOON_ORIGIN | Публичный origin для проверки запросов на изменение мира |

Для общего доступа запустите один экземпляр Node за HTTPS-прокси.
Разрешите потоку SSE `/api/events` работать без буферизации. Браузер
и API обслуживаются с одного адреса. Текущие координаты игроков живут
в процессе сервера и при полном перезапуске возвращаются к спавну.

Для домашнего Windows-сервера установите Tailscale, войдите и запустите
`Start-Internet.cmd` из распакованной сборки от имени администратора.
После первого подтверждения Funnel выдаёт HTTPS-адрес. Поделитесь им с
игроками и держите окно открытым во время игры. Игрокам нужен браузер.
[Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel)

Клавиша T открывает чат. Удержание Tab показывает игроков на сервере.
Клавиша K открывает общие часы, где можно поменять время и заморозить его.

```sh
node server/backup.mjs
node server/backup.mjs state/backups/manual.sqlite
```

Команда создаёт согласованный снимок работающей SQLite. Для восстановления
остановите сервер и укажите копию в `HONEYMOON_STATE`. Храните с копией
версию импортированной карты или исходные регионы. При смене базовой
карты сервер переносит изменения по стабильным ключам и печатает
конфликты. Конфликты также записываются в таблицу `rebase_conflicts`.

## Проверки

```sh
npm test
node world/audit.mjs
node qa/browser.mjs
node qa/desktop-play.mjs
node qa/chisel-desktop.mjs
node qa/chisel-fluids-desktop.mjs
node qa/audio.mjs
node qa/building-survey.mjs generated/world work/building-survey/extended generated/models --extended
```

Браузерный сценарий использует установленный Microsoft Edge, URL из
`HONEYMOON_URL` или локальный адрес выше. Запускайте его с отдельной
тестовой SQLite. Скриншоты и измерения сохраняются в `work/browser-qa/`.
Обход сохраняет координаты, дверные действия и точки съёмки в `work/building-survey/`.
Результаты сверки с Minecraft 1.4.7 описаны в [отчёте об обходе](qa/REFERENCE-ROUTE.md).
В [отчёте](REPORT.md) описаны замеры и визуальные замены, в
[описании импорта](import/README.md) — формат данных.
