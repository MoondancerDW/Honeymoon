Honeymoon — локальная версия для Windows x64

1. Распакуйте весь ZIP в одну папку.
2. Запустите Start-Honeymoon.cmd двойным щелчком. Откроется браузер.
3. Нажмите «Войти в мир». Если вкладка не открылась, введите в адресной
   строке браузера http://127.0.0.1:4173/.

Держите окно запуска открытым, пока играете. Для остановки нажмите Ctrl+C
в этом окне. Игра запускается с готовой картой, моделями, текстурами и
звуками без установки Minecraft, Java, Python или Node.js. Нужен современный
браузер с WebGL 2, например Microsoft Edge.

WASD — ходьба, мышь — обзор, пробел — прыжок, Esc — пауза.
Q или средняя кнопка копирует блок, ПКМ взаимодействует или ставит блок,
ЛКМ ломает блоки, которые вы установили сами.
V включает резец 1/8. Q берёт материал, ЛКМ вырезает кубик, ПКМ добавляет.
F включает полёт. В полёте пробел поднимает, Shift опускает.

На экране входа можно задать ник и выбрать PNG-скин Mine Little Pony.
Игроки, подключённые к одному серверу, видят пони друг друга. Для проверки
на одном ПК откройте один и тот же адрес в двух разных профилях браузера.

Сохранение создаётся в папке state. Используйте тот же браузер и профиль,
чтобы игра узнавала ваши блоки после перезапуска.

Для игры по локальной сети запустите Start-Honeymoon.cmd --lan из командной
строки в папке игры. Другие игроки открывают в браузере адрес этого ПК
с портом 4173, например http://192.168.1.10:4173/. Если Windows спросит,
разрешите подключение через частную сеть. Запуск двойным щелчком открывает
сервер только для текущего ПК.

Если порт 4173 занят, можно открыть командную строку в папке игры и выполнить
Start-Honeymoon.cmd --port 4174. Остановите первый экземпляр перед повторным
запуском из той же папки.
