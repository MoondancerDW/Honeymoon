Скрипты анализа сохранения Lilium Moonlight

Нужны Python 3.10 или новее и Pillow для проверки текстур.
Пути определяются относительно расположения tools/, поэтому диск, имя пользователя
и текущая рабочая папка не имеют значения. Содержимое sources/ только читается.

Из корня репозитория:
python tools/honeymoon_inventory.py
python tools/honeymoon-detail.py
python tools/honeymoon-cover-patterns.py
python tools/honeymoon-candidate.py
python tools/honeymoon-core-crop-audit.py

Каждый скрипт можно запускать независимо. Новые отчёты записываются в analysis/rerun/.
Исходные отчёты в analysis/ сохранены для сопоставления.

inventory: заголовки регионов и выборка вокруг спавна (до 33 x 33 чанков).
detail: детализация реестра и типичных TileEntities той же выборки.
cover-patterns: анализ составных микроблоков той же выборки.
candidate: сравнение областей 128 x 128 и 192 x 192 блока.
core-crop-audit: подробный аудит района X/Z от -64 до 63, то есть 64 чанков.

Это исследовательские скрипты для данного сохранения, не готовый универсальный
импортёр. Они не проверяют полностью все чанки всей карты. Для продакшен-импортёра
нужны отдельные проверки границ, повреждённых данных и неизвестных форматов.
В переносимой версии inventory чтение FML-реестра исправлено на ModItemData;
в историческом honeymoon-inventory.json поля FML_items и FML_item_keys пустые.
Точный реестр для аудита района читался через ModItemData изначально.

Подготовка исходной карты и проверка ресурсов описаны в project/README.md.
